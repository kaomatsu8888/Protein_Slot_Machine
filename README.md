# 🎰 コンビニたんぱく質ガチャ（Protein Slot Machine）

コンビニで買える食品を組み合わせて、**設定した予算内**で**目標たんぱく質量以上**になるセットをランダムに提案する Web アプリです。
HTML / CSS / JavaScript だけで動き、データベースや外部 API は使いません。

---

## 主な機能

| 機能 | 内容 |
| --- | --- |
| コースプリセット | 「肉体改造・健康維持・ダイエット」と体重から、1食分の目標量を自動計算 |
| 目標たんぱく質量（必須） | 1〜300g。全角数字も入力可 |
| 予算（必須） | 100〜10,000円（整数） |
| 重複OK | チェックすると同じ商品を最大3個まで入れられる |
| ガチャ | 商品名がスロットのように切り替わる演出のあと、結果を表示（タップでスキップ可） |
| 結果表示 | 商品ごとのカード（商品名・価格・たんぱく質量）、合計金額・合計たんぱく質量・予算残り |
| もう一回引く | 同じ条件で再抽選 |
| 該当なし | 予算内で集められる最大量を示し、条件の見直し方を案内 |
| 入力チェック | 空欄・数字以外・範囲外・小数の予算をエラー表示 |
| 入力保持 | 前回の入力値を localStorage に保存し、次回開いたときに復元 |
| レスポンシブ | スマートフォン幅（〜480px）に最適化 |

## 起動手順

`products.json` を `fetch()` で読み込むため、**ローカルサーバー経由で開く必要があります**
（`index.html` をダブルクリックで直接開くと、ブラウザの制限でデータを読み込めません）。

### 方法1：Python（macOS は標準で入っています）

```bash
cd Protein_Slot_Machine
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。終了は `Ctrl + C`。

### 方法2：VS Code の拡張機能「Live Server」

`index.html` を右クリック →「Open with Live Server」。

### スマートフォンで確認する場合

PC とスマートフォンを同じ Wi-Fi に接続し、方法1で起動したうえで、スマートフォンから `http://<PCのIPアドレス>:8000` を開きます。

## 抽選ロジック

1. 重複OKなら各商品を3個ずつ、そうでなければ1個ずつ並べた「母集団」を作る
2. 母集団をシャッフルし、予算に収まる商品を順に入れていき、目標に届いたら確定（**ランダム貪欲法**）
3. 2 を最大300回試しても見つからなければ、**動的計画法（0/1 ナップサック）** で予算内の最大たんぱく質量を求める
   - 最大量が目標以上 → そのセットを結果にする
   - 目標未満 → 「条件に合う組み合わせなし」として最大量を案内する

たんぱく質量は内部で 0.1g 単位の整数に変換して計算しています（小数の足し算で生じる誤差を避けるため）。

## コースの係数

1日の目安量 ＝ 体重(kg) × 係数、これを3食で割った値を「1食分の目標」としてセットします。

| コース | 係数（g/kg/日） | 例：体重60kg の 1食分 |
| --- | --- | --- |
| 肉体改造 | 2.0 | 40g |
| 健康維持 | 1.0 | 20g |
| ダイエット | 1.5 | 30g |

> 係数は一般的な目安を丸めたもので、医療・栄養指導を目的としたものではありません。

## 商品データ（products.json）の形式

```json
{ "id": 1, "name": "サラダチキン プレーン", "price": 248, "protein": 23.8, "category": "チキン" }
```

| キー | 型 | 内容 |
| --- | --- | --- |
| id | 整数 | 商品ID（重複不可） |
| name | 文字列 | 商品名 |
| price | 整数 | 税込価格（円） |
| protein | 数値 | たんぱく質量（g） |
| category | 文字列 | チキン / 卵 / 乳製品 / 飲料 / 大豆 / 主食 / 魚介 / 菓子 |

カテゴリを追加する場合は `script.js` の `CATEGORY_EMOJI` にアイコンを追加してください（未登録なら 🛒 が出ます）。
形式が正しくない商品は読み込み時に自動で除外されます。

## 要件のうち、こちらで決めた点・曖昧な点

元の要件で決まっていなかった項目は、以下のように決めて実装しています。変更したい場合はお知らせください。

| # | 項目 | 今回決めた内容 | 検討の余地 |
| --- | --- | --- | --- |
| 1 | 目標量は「1日分」か「1食分」か | **1食分**（1日量 ÷ 3食）としてプリセット | 1日分のまとめ買い想定なら ÷3 をやめる |
| 2 | コースの係数 | 肉体改造 2.0 / 健康維持 1.0 / ダイエット 1.5（g/kg） | 性別・年齢・活動量を考慮するか |
| 3 | 体重は必須か | **任意**（プリセットを使うときだけ必要） | 必須にしてもよい |
| 4 | 重複OK時の上限 | 同じ商品は**最大3個** | 個数を可変にする |
| 5 | 1セットの商品数の上限 | 上限なし（目標到達で打ち切るため実際は数個） | 「最大5品まで」などの制限 |
| 6 | 入力範囲 | 目標 1〜300g、予算 100〜10,000円、体重 20〜200kg | 範囲の見直し |
| 7 | 「目標以上」の超過分 | どれだけ超えても可 | 超過を目標の+○g以内に抑える |
| 8 | 抽選の公平性 | 達成できる組み合わせから厳密に均等ではない（ランダム貪欲法） | 全組み合わせを列挙して均等抽選 |
| 9 | 予算を余らせてよいか | 余ってよい（予算残りを表示） | 予算ギリギリを優先する |
| 10 | 前回入力の保持範囲 | 入力値のみ。抽選結果は保存しない | 前回の結果や履歴も残す |
| 11 | 商品の価格・栄養値 | **架空のサンプル値** | 実データに差し替える場合は出典の管理が必要 |
| 12 | アレルギー・カテゴリ除外 | 未対応 | 「乳製品を除く」などのフィルタ |
